# 大屏可视化设计文档

> 科技风大数据可视化大屏的设计与实现：风格、配色、布局、组件、动效、图表规范。

---

## 1. 设计理念

大屏的定位是「**让数据会说话**」：运营与管理者一屏掌握用户流失全局。设计遵循三条原则：

1. **克制的科技感**：动效、光效服务于可读性，避免喧宾夺主；
2. **信息层级分明**：中心是「预测核心」，两侧是「分析面板」，底部是「洞察流动」；
3. **数据驱动**：每一个图表都由后端真实统计驱动，洞察由规则自动生成，无硬编码。

## 2. 风格基调

| 风格关键词 | 落地方式 |
|-----------|---------|
| 深色暗星空背景 | 深空蓝 `#040a18` + 两层 CSS 星云光晕 |
| 粒子微弱动效 | Canvas 星辰漂移 + 偶发流星，透明度克制 |
| 模块边框外发光 | 面板青色描边 + 四角括弧 + hover 提亮 |
| 线条流光扫边 | 面板顶部 2px 渐变流光反复扫过 |
| 中心图形呼吸光晕 | 中心仪表盘数值呼吸缩放 + 光晕脉动 |
| 深蓝 + 荧光青主色 | `#0a1736` / `#00d8ff` |

## 3. 配色系统

设计遵循「颜色按职责分配」的方法论，并做了色盲安全验证（CVD）。

### 3.1 角色色板（CSS 变量）

| 角色 | 色值 | 用途 |
|------|------|------|
| 页面底色 | `#040a18` | 深空背景 |
| 面板表面 | `rgba(9,22,52,.62)` | 半透明科技面板 |
| 主色-荧光青 | `#00d8ff` | 标题/边框/强调/主图表 |
| 主色-深蓝 | `#3d7bff` | 次级强调 |
| 文字-主 | `#e6f6ff` | 标题/数值 |
| 文字-次 | `#9fc6ec` | 标签 |
| 文字-弱 | `#5f7fa8` | 辅助/刻度 |

### 3.2 分类色（已验证 CVD）

用于「设备占比」等部分-整体图，固定顺序分配：

```
#00a2b5 #3d7bff #c7548c #c98200 #8f7ad9 #cf3d4d
```

### 3.3 顺序色阶（流失率高低）

单色阶、由亮到深，用于流失率条形图：

```
#37f4ff → #00d8ff → #00b0e0 → #0088c6 → #0060a8 → #004088
```

### 3.4 发散对（相关性）

负（保护留存）= 荧光青，正（推高流失）= 风险红，0 = 中性灰。

### 3.5 状态色（风险分级）

| 风险 | 色值 | 含义 |
|------|------|------|
| 低 | `#00e676` | 留存良好 |
| 中 | `#ffb300` | 存在倾向 |
| 高 | `#ff3d6e` | 重点干预 |

## 4. 布局设计

```
┌─────────────────────────────────────────────────────────┐
│  顶栏：模型指标徽章  │ 居中发光标题 + 流光装饰翼 │ 实时时钟  │
├──────────────┬────────────────────────────┬─────────────┤
│ 左列          │         中列               │ 右列         │
│ · 核心运营指标 │ · 流失风险仪表盘（呼吸光晕）  │ · 渠道流失率  │
│ · 设备占比     │ · 用户风险预测表单          │ · 特征相关性  │
│ · 年龄段流失率 │                            │ · 训练监控    │
├──────────────┴────────────────────────────┴─────────────┤
│  底部跑马灯：模型指标 + 经营洞察                          │
└─────────────────────────────────────────────────────────┘
```

- 三栏等权（1 : 1.12 : 1），中列承载预测核心；
- 1080p 满屏适配，窄屏自动降级为单列滚动。

## 6. 动效设计（克制的科技感）

| 动效 | 实现 | 强度 |
|------|------|------|
| 顶部流光 | `@keyframes sweep`，渐变条横向扫过 | 2px 细线，低调 |
| 纵向扫描 | `@keyframes scanline`，极淡渐变下移 | opacity ≤ 0.045 |
| 呼吸光晕 | `@keyframes breathe`，仪表盘数值缩放+光晕 | 4s 周期 |
| 装饰环旋转 | `spin` 单层虚线环 | 40s 慢速 |
| 流星 | Canvas 随机生成 | 每 ~6s 一颗 |
| 图表动画 | ECharts 内置动画（数值/进度/入场） | `valueAnimation` 等 |
| 跑马灯 | `ticker` 位移 + mask 渐隐 | 40s 循环 |

> 关键原则：**动效不抢数据**。流光/扫描线透明度极低，数值与图表始终清晰。

## 7. 图表规范（方法论沉淀）

图表遵循数据可视化设计方法（dataviz），并通过 ECharts option 落地：

1. **先选形式，再上颜色**：流失率比较用条形图（顺序编码），部分-整体用环形图（分类编码），相关性用发散条形图；
2. **单色阶优先**：能用一个色阶表达就不上多色，避免「彩虹图」；
3. **分类色固定顺序**：同类图表分类色顺序一致，绝不按排名换色；
4. **标记规范**：通过 `itemStyle` 落地——条形圆角锚定基线、环形 2px 表面间隙（borderWidth）、渐变发光；
5. **交互必备**：每个图表配置 tooltip 浮层；≥2 序列必配图例；
6. **文本不穿系列色**：数值/标签用文字色，颜色由旁边的标记承载；
7. **色盲安全**：分类色板通过 CVD 对比验证（正常视觉 ΔE ≥ 15），主题与图表共用同一套色板。

## 8. 响应式与性能

- **响应式**：`grid-template-columns` 三栏 → 单栏降级；ECharts 通过 `ResizeObserver` + window resize 自适应容器；
- **性能**：`echarts/core` 按需引入，仅注册 Pie/Bar/Line/Gauge 四种图表；构建时 `manualChunks` 将 echarts 拆为独立 vendor 包（gzip 约 203KB，浏览器缓存友好）；Canvas 星空用 `requestAnimationFrame` + 组件卸载清理（EChart 卸载时 `dispose()`）；
- **无障碍**：语义化标签 + `aria-hidden` 装饰元素。

## 9. 为什么用 ECharts？

大屏定位是「**展示给业务方/面试官看**」，首要目标是**标准专业的观感**，因此选择 ECharts：

| 维度 | ECharts | 手写 SVG |
|------|---------|----------|
| 专业观感 | ✅ 开箱即用的成熟视觉与交互（tooltip/动画/缩放） | 需自行打磨 |
| 可视化能力 | 20+ 图表类型，后续可扩展地图/桑基/仪表盘 | 每种图都要手写 |
| 定制 | 注册「tech-dark」主题 + option 精细配置 | 完全可控但工作量大 |
| 包体 | 按需引入 + 分包，gzip ≈ 203KB | 最小 |

**本项目的取舍**：
- 图表层用 ECharts（标准、专业、可扩展）；
- 装饰/氛围层（星空粒子、流光边框、呼吸光晕）用自研 CSS/Canvas——这是 ECharts 不擅长、也是体现前端功底的亮点；
- 一套「tech-dark」主题 + 验证过的配色，保证 ECharts 与大屏风格完全统一。
