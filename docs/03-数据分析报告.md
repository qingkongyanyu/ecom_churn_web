# 电商用户流失 数据分析报告

> 数据源：`data/churn_data.csv`（500 条模拟电商用户样本）
> 目标变量：`churn`（0=留存，1=流失）

---

## 1. 数据概览

| 项目 | 数值 |
|------|------|
| 样本总量 | 500 |
| 特征数 | 18（5 分类 + 13 数值） |
| 流失样本 | 249（49.8%） |
| 留存样本 | 251（50.2%） |

样本类别基本均衡，模型可直接使用准确率 / AUC 评估，无需重采样。

---

## 2. 分类维度 · 流失率透视

| 维度 | 高流失分组 | 流失率 | 样本量 | 与均值偏差 |
|------|-----------|--------|--------|-----------|
| 年龄段 | **55+** | **80.0%** | 25 | **+30.2pp** |
| 年龄段 | 18-24 | 57.7% | 111 | +7.9pp |
| 年龄段 | <18 | 26.1% | 23 | -23.7pp |
| 渠道 | **Social** | **57.1%** | 63 | +7.3pp |
| 渠道 | Referral | 41.7% | 12 | -8.1pp |
| 系统 | **Linux** | **62.5%** | 16 | +12.7pp |
| 设备 | Tablet | 39.6% | 48 | -10.2pp |
| 设备 | Mobile / PC | ≈50% | — | 与均值持平 |

**解读**
- 年龄段呈 U 型：最年轻（<18）与中年（45-54）留存最好，**55+ 与 18-24 是高风险群体**。
- Social 渠道用户流失明显高于均值，可能是内容引流质量/匹配度问题。
- 设备端差异较小，Tablet 用户相对忠诚。

---

## 3. 数值特征 · 相关性分析

| 特征 | 与流失的相关性 | 留存均值 | 流失均值 | 解读 |
|------|--------------|---------|---------|------|
| buy_freq（下单次数） | **-0.68** | 22.7 | 5.3 | 强保护信号 |
| total_spend（累计消费） | **-0.68** | 9850 | 1484 | 强保护信号 |
| active_days_30d（活跃天数） | **-0.65** | 14.8 | 4.3 | 活跃即留存 |
| total_pages_visited（访问页数） | **-0.63** | 119 | 43 | 粘性指标 |
| register_days（注册天数） | -0.62 | 533 | 265 | 新用户易流失 |
| last_buy_days（距上次下单） | **+0.65** | 12.0 | 49.4 | 沉睡预警 |
| days_since_last_login（距上次登录） | **+0.64** | 7.6 | 33.9 | 流失前兆 |
| cart_total / fav_total | -0.54 / -0.44 | — | — | 浏览行为弱保护 |
| refund_cnt（退款次数） | +0.16 | 0.40 | 0.66 | 弱风险信号 |
| member_level / avg_order_amount | -0.18 / -0.15 | — | — | 弱保护 |

**结论**：流失本质上是「**沉默 + 低价值**」：登录/下单间隔拉长、消费与活跃骤降。运营应聚焦唤醒而非单纯拉新。

---

## 4. 分群洞察（规则化）

| 人群 | 流失率 | 占样本 | 建议 |
|------|--------|--------|------|
| 沉睡用户（>30 天未下单） | **92.2%** | 193 / 500 | 召回券 + 定向 Push，避免永久流失 |
| 低活跃（30 天活跃 ≤3 天） | ≈87% | 高 | 轻量任务 + 签到激励 |
| 低消费（≤2000 元） | 94.0% | 高 | 客单价提升 / 权益引导 |
| 低频（下单 ≤5 次） | 94.1% | 高 | 复购券 + 会员等级升级路径 |
| 忠诚用户（下单 ≥20 次） | 极低 | 中 | 保持现状，VIP 关怀 |
| 55+ 高龄用户 | 80.0% | 25 | 专属客服 + 简化操作引导 |

## 5. 模型表现

| 指标 | 值 |
|------|-----|
| 准确率 Accuracy | **92.16%** |
| AUC | **0.9154** |
| 留存召回率 | 92.31% |
| 流失召回率 | 92.00% |
| 混淆矩阵 | [[24, 2], [2, 23]]（测试集 51 条） |

模型结构：MLP `18 → 64 → 32 → 1`，BatchNorm + Dropout(0.3)，Adam(lr=1e-3, wd=1e-4)，
BCELoss + 早停（patience=15），最佳轮次 Epoch 42（Val Loss 0.1520）。

> 注：数据集为模拟数据，特征与标签相关性较强，模型表现高于真实业务常见水平；落地需用真实数据重新训练评估。
