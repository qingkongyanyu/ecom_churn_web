# 模型设计文档

> ANN-MLP 用户流失预测模型：从问题定义、数据预处理、网络结构、训练策略到评估与优化空间。

---

## 1. 问题定义

电商用户流失预测是一个**二分类问题**：

- 输入：18 个用户特征（5 个分类 + 13 个数值）
- 输出：流失概率 `P(churn) ∈ [0,1]`，配合阈值划分风险等级

```
低风险  P < 0.3  （绿色）
中风险  0.3 ≤ P < 0.7（橙色）
高风险  P ≥ 0.7  （红色）
```

## 2. 数据预处理（core/dataset.py）

| 步骤 | 做法 | 说明 |
|------|------|------|
| 读取 | `pd.read_csv(encoding='utf-8-sig')` | 兼容 BOM |
| 清洗 | 丢弃 `user_id` | 非预测性列 |
| 编码 | `LabelEncoder` 编码 5 个分类列 | 保存 encoders.pkl 供推理复用 |
| 划分 | `train_test_split` 分层抽样 | 训练:验证:测试 = **7:2:1** |
| 标准化 | `StandardScaler.fit(X_train)` | **只在训练集上 fit**，防数据泄露 |
| 持久化 | 保存 scaler / encoders / feature_cols | 推理只读，不重算 |

**关键工程约束**：推理阶段绝不重新 fit，全部复用训练导出的 pkl —— 这是「训练推理同源」的根基。

## 3. 模型选型：为什么是 ANN-MLP？

| 方案 | 优点 | 本项目选择理由 |
|------|------|----------------|
| **ANN-MLP** | 可学习非线性关系、灵活、易演示 | 结构化表格数据 + 中小样本，MLP 够用且直观 |
| XGBoost/LightGBM | 表格数据通常更强 | 作为后续对比基线（见 §7） |
| 逻辑回归 | 可解释强 | 无法捕捉非线性交互 |

> 诚实说明：500 条模拟数据规模小、特征与标签相关性较强，MLP 已能取得较好表现；真实大数据场景建议对比 GBDT 系模型。

## 4. 网络结构

```
输入层 (18)  ──► 全连接 64 ──► BatchNorm1d ──► ReLU ──► Dropout(0.3)
                 │
                 ▼
              全连接 32 ──► BatchNorm1d ──► ReLU ──► Dropout(0.3)
                 │
                 ▼
              全连接 1 ──► Sigmoid ──► 流失概率
```

**结构设计意图：**
- **BatchNorm1d**：稳定训练、加速收敛、允许较大学习率；
- **Dropout(0.3)**：随机失活抑制过拟合；
- **Sigmoid 输出**：将 logits 映射到 [0,1]，配合 BCELoss。

## 5. 训练策略（core/train.py）

| 超参数 | 值 | 说明 |
|--------|-----|------|
| 优化器 | Adam | 自适应学习率，适用于中小网络 |
| 学习率 | 1e-3 | 适中，配合 BN 收敛稳定 |
| L2 正则 weight_decay | 1e-4 | 抑制过拟合 |
| 损失函数 | BCELoss | 二分类交叉熵 |
| Batch Size | 32 | 349 训练样本 → 11 batch/epoch |
| 最大轮次 | 200 | 配合早停兜底 |
| **早停 patience** | **15** | 连续 15 轮验证集无改善即停止 |
| 随机种子 | 42 | 可复现 |

**早停机制**：监控验证集 Loss，`val_loss < best - 1e-4` 视为改善并保存最优权重；否则计数，达 patience 停止。

## 6. 评估结果

### 6.1 指标

| 指标 | 值 |
|------|-----|
| 准确率 Accuracy | **92.16%** |
| AUC | **0.9154** |
| 留存召回率 | 92.31% |
| 流失召回率 | 92.00% |

### 6.2 混淆矩阵（测试集 51 条）

```
             预测留存(0)  预测流失(1)
实际留存(0)     24            2
实际流失(1)      2           23
```

- 两种错误的代价不同：**漏判流失（假阴性）代价更高**（用户真的流失了）。
- 当前流失召回率 92%，说明对真正的流失用户识别较充分。

### 6.3 Loss 曲线

![训练/验证 Loss 曲线](images/loss_curve.png)

- 训练 57 轮早停触发；
- **最优轮次 Epoch 42**，验证集 Loss 0.1520；
- 训练 Loss 与验证 Loss 同步下降，无显著过拟合（两线未明显拉开）。

## 7. 改进空间（面试加分项）

| 方向 | 做法 | 预期收益 |
|------|------|----------|
| 换更强模型 | 对比 XGBoost / LightGBM / 交叉验证 | 表格数据常见更优 |
| 特征工程 | 衍生特征（消费间隔、近 7 天活跃、RFM 分箱） | 提升判别力 |
| 类别不平衡处理 | 真实数据若不平衡：类别权重 / Focal Loss / 过采样 | 提升少数类召回 |
| 阈值调优 | 基于业务代价选择最优阈值（而非固定 0.5） | 精准控制漏判率 |
| 时序建模 | 引入会话序列 / 行为轨迹，尝试 LSTM | 捕捉时间动态 |
| 模型可解释 | SHAP / LIME 分析特征贡献 | 可解释性，业务信任 |
| 线上化 | 量化/ONNX 导出 + 批量预测 | 推理提速 |
