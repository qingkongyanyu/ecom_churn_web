# 部署与运维指南

> 从零搭建环境、本地运行、到生产化建议与常见问题排查。

---

## 1. 环境要求

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.10.x | `pyproject.toml` 限定 `>=3.10,<3.11` |
| Node.js | ≥ 18（推荐 20+） | 前端构建 |
| 包管理 | uv（推荐）/ pip | Python 依赖 |
| 系统 | Windows / macOS / Linux | 全平台 |

## 2. 本地部署（开发模式）

```bash
# ① 克隆项目
git clone <repo-url> && cd ecom_churn_web

# ② 安装 Python 依赖（二选一）
uv venv --python 3.10.11 && uv pip install -e .
# 或
python -m pip install -r backend/requirements.txt

# ③ 训练模型（生成 model_weight/ 与 metrics.json）
python core/train.py
#    输出示例：
#    准确率 Accuracy: 0.9216 | AUC: 0.9154
#    模型指标已保存至 model_weight/metrics.json

# ④ 启动后端（http://127.0.0.1:8000，Swagger: /docs）
python backend/main.py

# ⑤ 启动前端（http://localhost:5173）
cd frontend-vue
npm install
npm run dev
```

> 打开 http://localhost:5173 即可进入大屏。

## 3. 生产化建议

### 3.1 后端服务化

```bash
# 多 worker 并发（生产推荐）
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 4
```

- 使用 `backend.main:app` 字符串导入以支持多 worker / reload；
- 生产环境可加 `--proxy-headers`，置于反向代理之后。

### 3.2 Nginx 反向代理 + 静态托管

```nginx
# 前端构建产物托管
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    root /var/www/ecom_churn_web/frontend-vue/dist;
    index index.html;

    # SPA 路由回退
    location / { try_files $uri $uri/ /index.html; }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

前端生产构建：

```bash
cd frontend-vue && npm run build
# 产物在 frontend-vue/dist/
```

> 生产环境前端不再走 Vite 代理，改为 Nginx `/api/` 转发，前后端同域部署，天然无跨域问题。

### 3.3 Docker 化（可选用）

```dockerfile
# 后端
FROM python:3.10-slim
WORKDIR /app
COPY pyproject.toml ./
RUN pip install .
COPY . .
RUN python core/train.py
CMD ["uvicorn", "backend.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

> 提示：若在容器内训练，需保证 CPU 版 PyTorch 安装源正确（见 `pyproject.toml` 的 `tool.uv.sources`）。

### 3.4 安全与可靠性

| 项 | 建议 |
|----|------|
| CORS | 生产将 `allow_origins` 收敛为真实域名，勿用 `*` |
| 鉴权 | 增加 API Key / JWT 校验 |
| 输入校验 | Pydantic 已做类型/范围校验，非法分类值返回 400 |
| 模型安全 | `torch.load(weights_only=True)` 防止恶意 pickle |
| 监控 | 接入 /health 健康检查 + 日志采集 |

## 4. 常见问题排查

### Q1：启动后端报 `FileNotFoundError: ann_churn.pth`
**原因**：未先训练。执行 `python core/train.py` 生成 model_weight 全部产物。

### Q2：前端页面能打开，但图表数据为空 / 接口 404
**原因**：Vite 代理指向的后端未启动，或后端接口路径不符。
- 确认 `python backend/main.py` 已启动（`curl http://127.0.0.1:8000/health`）；
- 确认访问的是 `/api/dashboard`（代理原样转发，不 rewrite）。

### Q3：训练报 `ModuleNotFoundError: No module named 'matplotlib'`
**原因**：依赖未装全。`backend/requirements.txt` 已含 matplotlib，请按 §2 安装。

### Q4：`new_user` 等数值字段小数位过多 / 校验不过
前端 `step="any"` 允许小数，后端字段定义已做 `ge/le` 范围校验；整数型字段请传整数。

### Q5：预测返回 400「字段不在训练集类别中」
输入的分类值与训练集类别不一致。合法值见错误信息中的 `合法值: [...]` 提示。

### Q6：端口被占用
`python backend/main.py` 默认 8000，前端 5173；被占用时修改端口，并同步更新 `vite.config.js` 代理 target。
